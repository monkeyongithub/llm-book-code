## 配套代码概览

本项目配合《语言之舞：大语言模型应用实战全书》阅读，帮助读者把书中的概念、算法与应用流程对应到具体代码：看清输入如何处理、关键步骤为什么这样组织，以及输出能说明什么。

项目按书稿章节组织，包含 **87 个 Python 文件、1 个 HTML 文件和 11 份章级总览**。示例涵盖小型算法实验、模型调用、微调与部署、提示设计、RAG、工具调用和 Agent。部分文件提取了外部项目的核心流程，或用规则与模拟数据解释方法；其学习目标和使用范围见文件头及所在章的 `CHAPTER_OVERVIEW.md`。

## 如何配合书稿阅读

1. **先读书稿小节**：明确本节要解决的问题、输入输出和关键概念。
2. **打开章级总览**：通过“书稿小节—代码文件—用途”表找到对应示例，并查看建议阅读顺序。
3. **沿代码中的 Step 阅读**：把每一步注释与紧随其后的实现对应起来，观察数据和状态如何变化。
4. **比较同节的不同方法**：遇到 `T1、T2、T3` 时，先理解各方案的差异，再按脚本说明选择运行方式。
5. **做一个小实验**：修改一项输入或参数，预测结果，再观察输出并回到书稿解释原因。涉及模型效果时，使用一致的数据和评估口径。

可以随书逐章学习，也可以从当前阅读的小节直接进入。各案例的执行顺序以章级总览为准；例如，FLAN-T5 对齐微调需要先取得同节指令微调生成的适配器。

## 文件与注释约定

- **章节编号**：文件名开头的编号对应书稿小节。具体内容以书稿、文件头和章级总览中的说明为准。
- **Step1、Step2、Step3**：表示当前示例的核心处理步骤，注释放在对应代码附近。
- **T1、T2、T3**：表示同一主题的不同方法或方案。部分脚本通过 `--method` 选择方案，部分依次展示；请先阅读具体实现。
- **语言与术语**：代码注释和章级总览以中文为主，保留 token、embedding、LoRA、RAG 等术语，以及接口字段、函数名和命令的原始写法。英文 README 使用相同的文件路径。
- **资源路径**：配书脚本中的本地资源路径以项目根目录为基准；从根目录运行脚本。外部项目的命令按其说明在相应目录执行。

## 从两个小示例开始

准备 Python 3 环境，在终端进入项目根目录，也就是包含本 README 的目录。以下两个示例仅使用 Python 标准库，无需下载模型、准备 API 密钥或安装第三方依赖。

### 观察二元概率与平滑

对应书稿 **1.1.1 SLM（统计语言模型）**：

```bash
python3 "一、大语言模型的发展史/1.1 NLP技术发展的四波浪潮/1.1.1 SLM(统计语言模型)/1.1.1_二元语言模型与平滑.py"
```

比较最大似然估计与加一平滑的下一词分布，观察未见二元组和未知词的概率。可以调整语料或平滑系数，理解“为未见事件保留概率”的含义。

### 区分分类指标与困惑度

对应书稿 **2.3.1.2 常见的通用指标对比：ACC、P、R、F1、PPL**：

```bash
python3 "二、LLMs的核心要素/2.3 模型评估体系—指标与基准/2.3.1 模型评估指标/2.3.1.2 常见的通用指标对比/2.3.1.2_分类指标与困惑度.py"
```

观察真实标签与预测标签如何决定 ACC、P、R、F1，以及真实目标 token 的条件概率如何决定 PPL。分别修改预测标签或目标概率，理解这些指标各自衡量的对象。

如果当前环境使用 `python` 或 Windows 的 `py -3` 启动 Python 3，可替换命令中的 `python3`。路径包含空格、括号和中文，复制命令时请保留引号。

## 如何理解示例结果

- **把演示范围与书中目标对应起来。** 单头注意力、小矩阵 LoRA、单步解码和模拟监控分别展示对应机制的一部分；进一步实现可沿书稿给出的流程展开。
- **区分真实调用与规则模拟。** 第 7 章既有实际模型调用，也有提示模板、候选搜索、规则修订和投票示例。运行成功说明相应流程得到了执行，方法效果仍需在明确任务和数据上评估。
- **保持比较条件一致。** 小语料、少量训练步骤或模型辅助评分用于理解流程；比较模型能力时，应保持数据集、分词、指标尺度和生成参数等条件一致。
- **理解每个案例的边界。** 第 4 章 DDP 示例展示数据并行；书稿中的完整流水线部署还需要相应实现。第 8 章适配器合并展示权重合并过程，上下文能力取决于模型配置与适配器训练。
- **以实际资源和结果为依据。** 文件中的输出注释用于辅助阅读；模型采样、外部服务和数据内容都可能影响实际结果。
